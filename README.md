# BookVerse 📚

BookVerse is a responsive e-book website designed to help users explore and discover books online.

## 🌐 Live Demo

https://e-bookwebpage.netlify.app

## ✨ Features

- Responsive web design
- Book browsing interface
- Book categories
- Interactive user interface
- Clean and modern layout
- HTML, CSS and JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📸 Project

BookVerse provides a simple and user-friendly interface for exploring e-books.
